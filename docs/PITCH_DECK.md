# Pitch deck

The 8-slide deck is a Claude Slides artifact (exportable to PDF / PowerPoint from its Share menu):
https://claude.ai/artifact/G1quNokCHgeg9Xe5TqYRjC — private until shared by the owner.

1. **PRIVEIL**: Fund builders. Protect voters.
2. **The problem**: public votes invite pressure; allocation is easy to game; proof costs privacy.
3. **The solution**: a community can verify a round's outcome without seeing how any member voted.
4. **How it works**: create round → submit proposals → private eligibility → hidden ballots →
   no double votes → verified allocation.
5. **Why Midnight**: private witnesses on the device, public roots, nullifiers and commitments on
   the ledger; explicit `disclose()`.
6. **What's built**: 5 compiled circuits, 44 tests, 0 secrets found in public state, an
   end-to-end flow in CI.
7. **Market and adoption**: DAOs, ecosystems, grant programs, open-source communities, developer
   foundations; protocol fee plus a hosted tier.
8. **Roadmap**: Wave 3 MVP → preprod and threshold-encrypted ballots and credentials →
   quadratic funding, shielded payouts, multiple admins.
